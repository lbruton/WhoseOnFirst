Design Notes

Sidebar Offcanvas

  • Hamburger toggle at top-left (44px touch target)
  • 280px drawer width on 375px viewport
  • Semi-transparent overlay behind drawer
  • Brand logo (banner-logo-compact.svg) at header
  • Admin avatar with gold star badge
  • Active nav item: green #10B981 with right border
  • Footer pinned: v1.6.0 + dark/light toggle
  • Dark sidebar persists across both page themes

Team Members List

  • Vertical list replaces card grid
  • Grip handle (ti-grip-vertical) for drag reorder
  • WCAG AA color avatars with member initials
  • Rotation badge (green circle with position number)
  • Drag state: 2deg rotation, green border, elevated shadow
  • Ghost state: 30% opacity where item was
  • Floating "Save Rotation Order" FAB after drag
  • 44px min touch targets on Edit/Deactivate buttons

Card-View Toggle

  • Button group: [Table] [Cards] with active highlight
  • Cards mode: stacked cards with key-value layout
  • Date + status badge on first row
  • Recipient + masked phone on second row
  • Message preview as italic footer with dashed border
  • Delivered = green badge, Failed = red badge
  • Toggle visible only below md breakpoint (d-md-none)
  • State persisted in localStorage per page

Brand Kit Integration

  • banner-logo-compact.svg in sidebar header
  • avatar-admin.svg for user badge (green + gold star)
  • Primary: #059669 / #10B981 (green gradient)
  • Accent: #FCD34D / #FBBF24 / #F59E0B (gold)
  • Sidebar dark: #1E293B / #334155 (slate)
  • Active indicator: #10B981 green
  • Dark backgrounds: #0f172a (base) / #1e293b (cards)
